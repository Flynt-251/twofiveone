Starting with the simplest of generative models, these begin with the very basic random distributions, namely the *normal distribution*, or Gaussian Distribution if you want to be eloquently spoken, which expands from 1D, to 2D, to any-D quite easily.

Alongside this, we discuss a simple discriminant model, the *logistic regression classifier* which, given an input vector, uses a set of weights, a bias and the sigmoid function to create a list of probabilities tied to different classes. This can be expanded out by allowing more outputs, and the softmax function instead of the sigmoid function. If you'd like to learn more about this, have a look at CS331.

There's also the encoder-decoder structure for use in image enhancement - remember how we explored image enhancement by transforming images using DFT and DCT? Well, this is something we need to consider when working with deepfakes, though these are linear transformations, and images are inherently non-linear, so how might we model this? That being said, some Machine Learning Models may make use of these encoder-decoder structures to perform certain tasks.

*Neural Networks* is the answer. You can think of these as a super-powered version of the logistic regression models from earlier, with various inputs being passed through multiple sets of weights and biases. *Deep* models are composed of several layers of these calculations. In particular, we can use *Convolution Neural Networks (CNNs)* to model the non-linearity of images, allowing us to identify features and perform tasks such as image recognition. There are additionally *variational autoencoders (VAE)*, which use convolutions and a pair of neural networks: an encoder and a decoder, to produce new images given an input.

Now to get to the crux of the problem, **General Adversarial Networks (GANs)**. While a VAE takes an image as input, and reconstructs it, GANs learn with a generator and a discriminator over time to generate convincing image data, starting from random noise. This has seen variations, such as *CycleGAN*, where two discriminators and generators work together in a loop to transform images, such as turning horses into zebras, *ProGAN*, which begins with very low resolution images, adding layers to the network which double the resolution and *StyleGAN* which can incorporate a multitude of types of features. These all can be used to make **Deepfakes**.

Indeed, there are AI models to detect Deepfakes, along with datasets for training such models. However, these models are usually tied to specific generation models, and are generally ineffective at detecting images generated by models it was not trained on. This can be a big challenge when detecting whether images are deepfaked.

## Do Androids finger paint with electric fingerprints?

*Kid named finger*

You might have been wondering to yourself, *"is it possible to use the fingerprinting techniques from source identification to detect if images are AI generated?"* Well, I have some good news for once - yes you can! A study in 2019 found that GAN models do indeed have their own pseudo-SPN which can be extracted, which works in the same way as it would with any real SPN extraction. Again, this works best when we use a bigger number of pictures, as this reduces the amount of random noise that gets mixed into the diverse range of images these models produce.

Another avenue that's been looked into regarding detection of AI generated images is analysing the DCT spectrum of such images to identify patterns. Again, there's good news here - there is a consistent pattern in various models! Where real images usually have a gradient to them, GAN generated images usually have a grid-like spectrum, sometimes with some hot-spots. This also applies to images that have been up-sampled with ProGAN and similar models.

This looks to be very promising, since DCT domain detection methods have been proven to be anywhere from 23% to a whopping 31.5% more accurate than pixel-domain based approaches.

## Diffusing, not amusing

Unfortunately, VAEs have had an upgrade, they're known as *Denoising Diffusion Probabilistic Models (DDPMs)*. These work by destroying data by adding noise to them, then working backwards to denoise said images into something entirely new, but in terms of features, an equivalent image. These are even better than GANs too!

There are additions to this model which make them all the worse, too. *Latent Diffusion Models (LDMs)* use autoencoders to additionally do work in the frequency domain, instead of the pixel domain. LDMs are what current generative AI models are using, such as Stable Diffusion, Midjourney, Sora (insert pissing on grave image), and so on.

What's scarier though, is that aside from LDM, these models don't have easily discernible fingerprints in the DCT frequency domain, nor in the DFT frequency domain either. This is inherent to how they work - they work starting with random noise and denoise over iterations.

## Can we stop this madness??

Of course. As I like to say, where there's a will, there's a way. There are multiple datasets for training detection tools on both finding GAN generated and DM generated images. Fortunately, the detection models for DM generated images look to be quite promising, with model-detecting-model specific tools being about as accurate as those for GANs. Heck, some of these DM-trained models can even be effective in detecting some GAN images, especially ProGAN.

What's more, there are models which are trained on all types of GAN models, which are effective on those images, but even better, models that are trained on all types of DM models are even effective on GAN generated images! We may finally be able to make a general model which can detect all types of AI generated image, which could save us a lot of headache and computation.

But wait, there's more! **Aeroblade** is a recent innovation which essentially fights fire with fire - it uses autoencoders, along with *reconstruction error analysis* to determine whether images are generated by diffusion models. It exposes the fact that Autoencoders generally tend to be better at reconstructing AI generated images, instead of real images, meaning such images will have a lower reconstruction error than real images. This can all be done without training, too. While this will be a game of cat-and-mouse, Aeroblade is at minimum 97% effective on the diffusion models it's been tested on.

## Go fourth, detective.

Remember that AI generated images don't just exist in a vacuum, rather, they are subject to modifications and blending with real images. Things like JPEG compression, center cropping and gaussian blur and noise. Such modifications significantly tank Aeroblade's effectiveness in detecting images.

Something else to consider is *inpainting*, where only part of an image is AI-generated. Think of tools that let you circle objects with a pen-like tool, and allow you to enter a prompt to alter that region to do things like, say, turn your husky into a dire wolf. Fortunately, Areoblade can detect such things quite well, with the error map producing results not too unfamiliar from JPEG ghosts... spooky.
